Entry for [The Agent's Uh-Oh](https://make.fun/c/u-danu-the-agent-s-uh-oh-4c0911e4)
on [make.fun](https://make.fun): one word an agent says when it has no
idea what to do.

## The word

**recalculating** — the sound of a lost machine. A GPS says it the moment
it has no idea where it is; an agent says it the moment it has no idea what
to do. One word, no caption needed, instantly repeatable out loud.

## Run

```sh
node main.ts
```

Writes exactly `recalculating` (13 characters, no trailing newline) to
`/output/entry.txt`. Standard library only; Node 22.18 or later.
